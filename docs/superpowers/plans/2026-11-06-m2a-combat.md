# M2a Combat — Wolf Pack, Dodge, Auto-aim, Mobile Controls — Implementation Plan

> **For agentic workers:** Implement this plan task-by-task, checking off each step. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable fight on the test ground: hero vs three ghost-wolf packs, with dodge roll, auto-aim, HP/hurt/death/respawn and ROV-style touch controls plus keyboard.

**Architecture:** Every number lives in `data/balance.json`, read through the `Balance` class. Gameplay objects (Hero, Wolf, WolfPack, TouchJoystick) each expose a pure `step()`/`handle_*()` API so headless tests drive them without input or physics frames. `_physics_process` / `_input` only feed those APIs. Art is generated in PixelLab first, so the code tasks animate real sprites.

**Tech Stack:** Godot 4.5.1 (gl_compatibility, GDScript), PixelLab MCP, Python 3 + Pillow for asset tools, xvfb for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-06-m2-design.md` (approved 2026-11-06, "ตามแผนไปก่อน"), plus `docs/spec-numbers.md`, `docs/skills.md`, `docs/art-style.md`. Branch `m2a/combat` from `m2/design`.

## Global Constraints
- Godot 4.5.1, gl_compatibility, nearest filter; tile 32; hero cell 64×64, feet anchor (32,54); Y-sort on World.
- All game numbers come from `data/balance.json`; tests read the same file. No literal tuning numbers in gameplay scripts.
- Damage = ATK × mult × (1 − DEF/(DEF+100)) × rand(0.9–1.1); crit 5% ×1.5; min 1 (`Combat.damage`, existing).
- Hero Lv1 with starting gear (bamboo bow ATK +8, trainee armor DEF +4 / HP +20) = HP 120, ATK 18, DEF 6.
- Wolf: HP 40+18(l−1), ATK 6+2(l−1), DEF 2+l, EXP 8+5l, run 140 px/s, respawn 20 s.
- Every PixelLab generation is estimated before running and logged in `docs/pixellab-budget.md`. Every image passes the art-style.md checklist; no transparent holes inside icon frames.
- Thai UI text uses Kanit (OFL), bundled with its licence file.
- Do not claim pass without running: `godot --headless --path . --script tests/run_tests.gd`, `python3 tools/test_assets.py`, and xvfb screenshots that were looked at.
- Out of scope here: EXP, loot, MP, skills firing, potions working, saving (M2b); bag/equip (M2c); web export / pran-play (owner postponed the repo split).

## Review Focus
1. Two thumbs at once: holding the joystick while pressing shoot or dodge must keep moving and also fire/roll → `test_multitouch_joystick_and_shoot` (Task 5).
2. A touch that starts on the right half or on a button must never grab the joystick → `test_right_half_touch_ignored` (Task 5).
3. Hero death while wolves are mid-bite/lunge: no damage lands on a dead or respawning hero, and the pack goes home → `test_pack_returns_when_hero_dies` (Task 4), `test_no_damage_while_dead_or_respawning` (Task 3).
4. Rolling out of a shot before the release frame must not loose an arrow afterwards, and a roll must not pass through posts → `test_roll_cancels_shot_no_arrow` (Task 3), `test_roll_stops_at_collider` (Task 6).
5. Locked target dies or leaves range before the release frame: arrow flies along the stored aim, no crash → `test_target_freed_before_release` (Task 3).
