# M4b + M4c Implementation Plan

> **For agentic workers:** Implement this plan task-by-task, checking off each step. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the 13 new 512×512 rooms in the game (w1, w3, e2 removed; e0 is the only arena) and add the farm-run exits, 4 waypoints, monster re-roll on waypoint/new game, minimap fog and the corner/full-screen minimap.

**Architecture:** Rooms stay separate pictures joined by warps (RoomSet + data/rooms.json). `tools/painted_rooms.py` learns per-room sizes; RoomSet/PaintedLayout use the room's own size. New pure rule classes (`FogGrid`, `Waypoints`, `RoomReset`) carry the logic and are unit-tested; `MiniMap` / `WorldMap` UI read them.

**Tech Stack:** Godot 4.5.1 GDScript, Python 3 (PIL, numpy, scipy) build tool, headless tests `tests/run_tests.gd`.

**Spec:** docs/superpowers/specs/2026-11-07-m4b-rooms-512.md, docs/superpowers/specs/2026-11-07-m4c-farm-links-fog-minimap.md

## Global Constraints
- Rooms 512×512, cell 8 px; old rooms 688×384 must still load (size is per room).
- Map = c0r0..c2r3 + e0 (13 rooms). Links to w1/w3/e2 are deleted; those exits are dead ends.
- e0 holds the four arena sets (w1 Lv2–3, e0 Lv4–5, e2 Lv6–7, w3 Lv8–10); each re-roll picks the set whose average level is closest to the hero's level, ties to the lower set.
- Approved numbers: exit label distance 48 px; fade 0.25 s out / 0.25 s in; arrival 40 px; calm 1.0 s; fog grid 16×16 cells of 32 px, reveal radius 96 px; minimap 96×96 (landscape) / 80×80 (portrait), 85 % opacity.
- Monsters re-roll only on waypoint travel or a new game (not on walking between rooms).
- Waypoints: c1r1, c0r2, c2r0, c2r1; unlock by touch; travel list on any unlocked waypoint.
- Fog shows on the minimap / full map only; the world is never darkened.
- Thai UI text; no new PixelLab spend without approval (waypoint stone prop ~10 gen is a separate ask).

## Review Focus
1. Save from before M4b (688×384 coordinates) loaded after it: hero must land on walkable ground, not in a tree.
2. Warp arrival in a 512-tall room on a 640×360 screen: camera must scroll; hero never off-screen.
3. Re-roll after waypoint: packs never spawn on or within aggro range of the arrival point.
4. Portrait phone: minimap must not overlap HUD bars or touch buttons.
5. A room visited before the fog save existed must show as fully fogged, not crash.
