## Rules added after batch 1 (owner 2026-11-07)

- No repeated set dressing between rooms (batch 1 repeated the big boulder bottom-right and the flower patch on the left): each room uses a different style reference picture and names where its own props go.

## Game changes (after the art passes)
1. `tools/painted_rooms.py`: read each room's size from its picture (512×512 now, 688×384 before), not a fixed `SIZE`. Walk grid, overlay, warps and debug sheet otherwise as now.
2. Camera: a 512×512 room is taller than the 640×360 landscape view, so the camera follows the hero and stops at the room edges (owner: "เลื่อนตามตัวละครหยุดที่ขอบพื้นที่"). Portrait view (360×640) fits the width and scrolls less.
3. Tests: existing room tests run on the new pictures (every route walkable, arrivals clear of warps, colliders match). Add a test that the camera never shows past the room edge. Headless + screenshots as usual.
4. Monster packs keep their current spec values (counts/levels unchanged); the random-pack reset, waypoints and minimap are the next step (M4c), with their own spec.
