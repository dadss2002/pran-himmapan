# M3f ลานสู้มอน (ห้องลานโล่ง 4 ห้อง)

สถานะ: เจ้าของให้ Claude เลือกและจัดวางเอง 2026-11-07 ("อยากได้พื้นที่ action monster เพิ่ม", "Claude สามารถจัดวางเองได้ไหม")
งบ gen: ประเมิน 100 (4 × create_image_pro 688×384 ห้องละ 25) · เพดาน 150

## 1. ทำอะไร
- เพิ่มห้องใหม่ 4 ห้อง ขนาด 688×384 เท่าห้องเดิม แต่ละห้องเป็นลานป่าโล่งกว้าง มีต้นไม้แค่ตามขอบ ใช้สู้มอนโดยเฉพาะ
- ใช้สไตล์เดียวกับห้องเดิม (ส่ง c0r1 เป็น style reference)
- ทุกห้องต่อกับแผนที่เดิมด้วยวาร์ปที่ขอบนอก ไม่แก้ห้องเดิมนอกจากเพิ่มวาร์ป
- ทางเดิน วาร์ป และจุดเกิดมอน คำนวณด้วย tools/painted_rooms.py ตัวเดิม

## 2. ตำแหน่งและมอน (ใช้ค่าสถานะจาก spec M3d §2 ทุกตัวอยู่ในช่วงเลเวลที่ spec กำหนด)

## 2.1 สิ่งที่เปลี่ยนตอนทำจริง
- ภาพ e2: เจนลานบึง 3 ครั้ง ได้ภาพมีกรอบทุกครั้ง ใช้ไม่ได้
  - เจ้าของสั่งให้ Claude จัดวางพร็อพ PixelLab เองแทน (2026-11-07)
  - เจ้าของเลือก: ป่าทึบร่มรื่น, กลางโล่งมีที่หลบเล็กน้อย, พื้นหญ้าตัดจากห้องวาดเดิม, เน้นต้นไม้ใหญ่ เรือนยอด พุ่ม ดอก เห็ด
  - ทำด้วย tools/compose_room.py และ data/compose/e2.json ไม่เสียเครดิต (0 gen)
  - ทางเดินและส่วนบังฮีโร่ใช้ mask จากรอยเท้าพร็อพ
  - **เจ้าของดูแล้วชอบแบบภาพวาดมากกว่า ("ลานแบบนี้สวยกว่า")** จึงกลับไปใช้ภาพ w1 กลับด้าน
  - เก็บตัวจัดวางไว้ใช้เฉพาะตอนเจ้าของสั่ง ตัวอย่างอยู่ที่ data/compose/e2_try.json
- ย้ายจุดเกิดลิงใน c2r0 และ c2r2 ให้ห่างจากวาร์ปใหม่ฝั่งตะวันออก (เดิมห่างแค่ 32–42 px จากจุดโผล่)
