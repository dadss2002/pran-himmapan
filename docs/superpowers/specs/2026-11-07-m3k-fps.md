# M3k — 60 fps ขึ้นไป (เจ้าของ 2026-11-07)

คำสั่ง: "อยากให้เป็น 60 fps+" / "ทำให้มากกว่า 60fps"
ที่อนุญาต: ปรับโค้ดให้เบา ไม่เปลี่ยนเกม · ลดความละเอียด UI บนมือถือ · ปิดเอฟเฟกต์เมื่อ fps ร่วงต่ำกว่า 60
เครื่อง: iPhone 15/16/17 ขึ้นไป (ยังไม่ได้วัดบนเครื่องจริง)

## สิ่งที่ทำ (ไม่มีตัวเลขเกมเปลี่ยน)

1. **โค้ดเบาลง** — cache ค่า balance/monster cfg, เปลี่ยน shader แฟลชเฉพาะตอนค่าเปลี่ยน,
   ปุ่มสัมผัสวาดใหม่เฉพาะตอนคูลดาวน์เปลี่ยน, HUD คำนวณตัวเลขสกิลทุก 0.25 วินาทีหรือตอนอัปเลเวล/เปลี่ยนของ
   - CPU ต่อเฟรมบนเซิร์ฟเวอร์: ประมาณ 1.4–1.8 ms เหลือ 0.55–0.9 ms
2. **Physics interpolation** — เกมคิดฟิสิกส์ 60 ครั้ง/วินาทีเหมือนเดิม แต่จอ 120 Hz วาดตำแหน่งที่อยู่ระหว่างกลาง
   ทำให้ภาพลื่นจริงมากกว่า 60 เฟรม
   - เปิดเฉพาะโลก (ตัวละคร มอน ลูกธนู) ส่วน HUD เมนู และตัวเลขดาเมจไม่ใช้
   - ตอนวาร์ป เกิดใหม่ และมอนกลับบ้าน จะรีเซ็ตเพื่อไม่ให้ตัวไถลข้ามแผนที่
3. **Canvas บนมือถือไม่เกิน 2 เท่า** — iPhone ปกติวาดที่ 3 เท่า การจำกัดไว้ 2 เท่าทำให้วาดพิกเซลน้อยลงประมาณ 56%
   - โลกเกมยังวาดที่ความละเอียดพิกเซลจริงเหมือน M3j จึงชัดเท่าเดิม
   - ตัวอักษร UI อาจนุ่มลงเล็กน้อย
4. **โหมดประหยัด** (`scripts/rules/perf_saver.gd`)
   - เปิดเมื่อ fps ต่ำกว่า 57 ติดกัน 3 วินาที
   - ปิดเมื่อ fps ถึง 59 ขึ้นไปติดกัน 10 วินาที
   - เมื่อเปิด จะซ่อนระลอกน้ำในบ่อ ไม่แสดงฝุ่นตอนกลิ้งและแสงตอนเก็บของ และมิเตอร์แสดงคำว่า "ประหยัด"
   - เอฟเฟกต์ที่ยังแสดงตามปกติ: ประกายตอนโดนตี อัปเลเวล และสกิล

## เกิน 60 fps บน Safari

- ต้องใช้ iPhone จอ 120 Hz คือรุ่น Pro หรือ iPhone 17
- Safari ล็อกไว้ที่ 60 ถ้าไม่ปิดค่านี้: ตั้งค่า → แอป → Safari → ขั้นสูง → Feature Flags → ปิด
  "Prefer Page Rendering Updates near 60fps"
- โหมดประหยัดพลังงานของ iPhone จำกัดไว้ที่ 30 fps เสมอ

## ทดสอบ

- `tests/test_perf.gd` ครอบคลุม:
  - จังหวะเปิด/ปิดโหมดประหยัด
  - เอฟเฟกต์ที่ถูกข้ามและที่ยังแสดง
  - ระลอกน้ำเมื่อเปลี่ยนห้อง
  - interpolation เฉพาะโลก
  - การจำกัด canvas 2 เท่าใน Web preset
- วัด fps บนเครื่องจริงไม่ได้จากเซิร์ฟเวอร์ ต้องให้เจ้าของอ่านตัวเลขจากมิเตอร์ FPS ในเกม
