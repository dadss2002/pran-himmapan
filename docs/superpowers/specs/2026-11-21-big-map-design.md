## วิธีสร้างในเกม (ร่าง)
- TileMapLayer 128×128 (พื้น) + ของตกแต่งเป็น Sprite2D Y-sort, ชน = จากช่อง grid ที่เป็นกำแพง + กล่องชนที่โคนต้นไม้/หิน
- หมอก มินิแมป เต็มจอ ขยายจาก 512 เป็น 4096 (ช่องหมอก 8 px → 512×512 ช่อง; ต้องวัดบนมือถือ)
- มอนเกิดใหม่เมื่ออยู่ไกลจอ (แทนการรีเซ็ตห้อง), หินวาร์ปเดิม 3 จุด
- เซฟ v5: เพิ่มตำแหน่งในแผนที่ใหญ่ + หมอก; เซฟ v4 โหลดได้ → ย้ายไปจุดเริ่ม (มีเทสต์)
