- **สำเร็จเมื่อ** เจ้าของเปิดเกมแล้ว
  - กดปุ่ม "สกิล" ใส่เจมแยกศรในศรทะลวง แล้วเห็นลูกศร 3 แนวจริง และ MP ที่ใช้เพิ่มตามที่หน้าจอบอก

- **ล้มเหลว (แม้ทำงานได้)** ถ้าผู้เล่นไม่รู้ว่าเจมเม็ดไหนใส่สกิลไหนได้ หรือตีบวกแล้วขั้นลดโดยไม่เห็นคำเตือนก่อน

## 5. เจมในสกิล
### 5.1 ช่องและการใส่
- ช่องตาม gems.md §3: เลเวลสกิล 1–9 = 1 ช่อง, 10+ = 2 ช่อง · สกิลที่ยังไม่ปลด (เลเวลสกิล 0) ใส่ไม่ได้
- แตะเจม → แตะช่อง · ช่องที่มีเจม = สลับ · ถอดฟรี เจมเก็บ EXP และออปชันไว้ · ใส่ได้เฉพาะป้ายตรงกัน
- ถอดเจมตอนกระเป๋าเต็ม: ไม่ให้ถอด ขึ้น "กระเป๋าเต็ม" (เหมือนถอดอุปกรณ์) · การสลับทำได้เสมอ
- เกมหยุดตอนเปิดหน้านี้ **[ผมเลือกเอง]** เหมือนกระเป๋า

### 5.2 ผลของเจม (ค่าที่ เจม Lv1 · "+x ต่อเลเวล" = บวกเพิ่มทีละ x จุดต่อเลเวลที่เกิน 1 เช่น ทวีคูณ Lv3 = ×1.37)
| เจม | ผล (Lv1) | แรงขึ้นต่อเลเวลเจม (Lv10 / Lv20) |
|---|---|---|
| แยกศร | ยิงเพิ่ม +2 ดอก **ทุกดอก**แรง 60% (ตามตัวอย่าง gems.md: 3 แนว แนวละ 81% เมื่อมีทวีคูณ) · ศรทะลวง = 3 แนว ห่างกัน 12° · ศรกระจาย = 7 ดอก กางพัดเป็น 63° **[มุมผมเลือกเอง]** | +1% |
| สะท้อน | โดนเป้าแรกแล้วลูกศรลูกใหม่เด้งไปเป้าใกล้สุดที่ยังไม่โดน แรง 80% · เจม Lv10 เด้ง 2 ครั้ง · ศรทะลวงเด้งครั้งเดียวจากเป้าแรก | +1% |
| ทะลุ | ทะลุเพิ่ม 2 ตัว (Lv10 = 3) · ใส่ศรทะลวงได้แต่ไม่มีผลเพิ่ม หน้าจอบอกไว้ | — |
| ศรนำวิถี | ลูกศรเลี้ยวหาเป้าใกล้สุด แรง 90% · ถ้าเป้าตายเลือกเป้าใหม่ · ระยะยิงนับระยะที่บินจริง | +0.5% |
| ทวีคูณ | ดาเมจ ×1.35 | +1% (×1.44 / ×1.54) |
| พิฆาต | คริของสกิลนี้ +15% (บวกกับคริตัวละคร) | +0.5% (+19.5% / +24.5%) |
| ดูดเลือด | ฟื้นเลือด 3% ของดาเมจทุกแบบที่สกิลนี้ทำ (รวมไหม้ เด้ง กระโดด) เศษสะสมไว้ | +0.1% (3.9% / 4.9%) |
| ธาตุ | ตามข้อ 3 · ออปชันอุปกรณ์ "ดาเมจธาตุ" เริ่มมีผล บวกกับ ×1.1 | +1% ดาเมจ |
| ขยาย, ยืดเวลา | ยังไม่มีสกิลป้ายตรงกัน เก็บไว้ได้ ขึ้น "ยังไม่มีสกิลที่ใส่ได้ (ใช้กับห่าศร Lv7)" | — |

### 5.3 สถานะบนมอน (เจมธาตุ)
- ไหม้: ทุก 1 วิ ดาเมจ 20% ของดาเมจที่โดนครั้งนั้น (หลังหัก DEF) ไม่คริ · โดนซ้ำ = เริ่มนับ 3 วิใหม่ ใช้ค่าที่สูงกว่า ไม่ซ้อน
- ช้าลง 40%: ความเร็วเดิน วิ่ง และโดดพุ่ง · โดนซ้ำ = เริ่มนับใหม่
- สายฟ้า: กระโดดไปอีก 1 ตัวที่ใกล้สุด ไม่เกิน 120 px
- เอฟเฟกต์: ไฟติดตัว น้ำแข็งเกาะ ประกายไฟฟ้า ทำด้วย vfx_workbench (0 gen)

### 5.4 รวมค่าในสกิลเดียว
- **MP:** MP ของสกิล × ตัวคูณทุกเจม × (1 − ออปชัน "MP สกิลนี้") · ใช้ค่าทศนิยมจริง แสดง 1 ตำแหน่ง
- **ดาเมจ:** ตัวคูณสกิล × ทุกเจม × (1 + ออปชัน "ดาเมจสกิลนี้")
- **คริ:** คริตัวละคร + พิฆาต + ออปชัน "คริสกิลนี้" (บวกกัน)
- **คูลดาวน์:** เลเวลสกิล + อุปกรณ์ + ออปชัน "คูลดาวน์สกิลนี้" ลดรวมไม่เกิน 30% (เพดานเดิม)

### 5.5 EXP เจม
- เจมที่ใส่อยู่ได้ EXP เท่าที่ตัวละครได้จากการฆ่า (หลังโบนัส EXP%) × (1 + ออปชัน "EXP ของเจมนี้") · 150 × g^1.7 ต่อเลเวล ตัน Lv20
- **ยังได้ EXP ต่อเมื่อตัวละครตัน Lv10 [ผมเลือกเอง]** (ไม่งั้นเจมไปไม่ถึง Lv20 ในเฟสนี้) · ตายไม่เสีย EXP เจม **[ผมเลือกเอง]**

## 6. ออปชันสุ่มบนเจม (มีผลเฉพาะสกิลที่ใส่)
| ออปชัน | ช่วง |

| ดาเมจสกิลนี้ | +3–8% |
| คูลดาวน์สกิลนี้ | −3–8% |
| MP สกิลนี้ | −4–10% |
| คริสกิลนี้ | +2–5% |
| EXP ของเจมนี้ | +10–25% |

- **ค่าคงที่ตลอด** ได้ค่าตอนดรอปแล้วไม่เปลี่ยนตามเลเวลเจม (เจ้าของสั่ง 2026-11-06)
- ไม่ขึ้นกับเลเวลมอนที่ดรอป **[ผมเลือกเอง]** (เจมดรอปมาเป็น Lv1 เสมอ)
- เจมที่ดรอปทุกเม็ดได้ระดับและออปชันตอนดรอป (ระดับสุ่มตามตารางเดียวกับอุปกรณ์)

## 7. ตีบวก
- **ตัวเลข** spec-numbers §7: โอกาส 100/95/90/85/75/60/50/40/32/25% · แร่ = ขั้น · ทอง = 100×ขั้น² · **ตีไม่ติด: ดูขั้นปัจจุบันของของ** ถ้า ≤+5 เสียแค่วัตถุดิบ ถ้า ≥+6 ลด 1 ขั้น (จาก +5 ตีไป +6 ไม่ติด = ยังเป็น +5) · ค่าหลัก +6%/ขั้น (+1–+6), +10%/ขั้น (+7–+10)
- **ค่าหลักที่เพิ่ม:** ทุกค่าหลักของชิ้นนั้น (ธนู = ATK, ชุด = DEF และ HP) · ATK และ DEF เก็บเป็นทศนิยม (สูตรดาเมจรับทศนิยมอยู่แล้ว) HP ปัดเป็นจำนวนเต็มต่อชิ้น **[ผมเลือกเอง]** → ชุดพรานฝึกหัด +1 = DEF 4.24 · HP 21
- **เปิดจาก:** กระเป๋า → แตะธนูหรือชุด (ที่ใส่อยู่หรือในกระเป๋า) → "ตีบวก" · **ตีได้เฉพาะธนูและชุด [ผมเลือกเอง]**
- **หน้าต่าง:** ค่าก่อน→หลัง, โอกาส, แร่ (มี/ต้องใช้), ทอง (มี/ต้องใช้) แดงเมื่อไม่พอ, คำเตือนแดงเมื่อของ ≥+6, ปุ่มปิดเมื่อไม่พอ · ผลขึ้นทันที ติด/ไม่ติด/ลดขั้น ไม่มีอนิเมชันลุ้น **[ผมเลือกเอง]**
- **ชื่อ:** "ธนูเขาควาย +6" ทุกที่ที่แสดงชื่อ · บันทึกเซฟทันทีหลังตี
- ยันต์กันถอย: ไม่ทำรอบนี้

## 8. หน้าจอ
- ปุ่ม "สกิล" ขนาดเท่าปุ่มกระเป๋า อยู่ทางซ้ายของปุ่มกระเป๋า · คีย์บอร์ด **N** **[ผมเลือกเอง]** (K = กลิ้ง, I/B = กระเป๋า)
- หน้าสกิล·เจม ตามภาพร่าง: ซ้ายสกิล + ช่องเจม, กลางเจมในกระเป๋า (ใส่ไม่ได้ = จาง), ขวารายละเอียด + ผลถ้าใส่แต่ละสกิล + MP ก่อน→หลัง
- ปุ่มสกิลบนจอเล่นแสดง MP จริงหลังเจม · ข้อความ "มาในเฟสถัดไป" ของเจมและแร่ในกระเป๋าเปลี่ยนเป็น "ใส่ได้ที่หน้าสกิล" / "ใช้ตีบวก"
- ทุกปุ่มแตะได้บนมือถือ ตรวจด้วย `tests/touch_check.gd`

## 9. ข้อมูลและเซฟ
- เจมเป็นของชิ้นเดียว `{id: "gem_<type>", count: 1, gem: {type, level, exp, rarity, opts, element?}}` · **ยกเว้น**เจมธรรมดา Lv1 EXP 0 ไม่มีออปชันและธาตุ ซ้อนกันได้ (มาจากเซฟเก่าเท่านั้น) และแยกออก 1 เม็ดตอนใส่
- `skills: {piercing: [gem|null, gem|null], spread: [...]}` · อุปกรณ์มี `plus` (0–10)
- version 3 · โหลด version 2 และ 1 ได้: เจมที่ซ้อนอยู่คงซ้อน (ระดับธรรมดา ไม่มีออปชัน; เจมธาตุสุ่มธาตุตอนแยก) · `plus` = 0 · สกิลยังไม่มีเจม — ไม่มีของเกิน 24 ช่อง
- ตรวจเซฟ: ชนิดเจม ระดับ ออปชันไม่ซ้ำ ค่าอยู่ในช่วง เลเวลเจม 1–20 `plus` 0–10 · ผิด = เริ่มใหม่ + เก็บ .bad.json (แบบเดิม)
