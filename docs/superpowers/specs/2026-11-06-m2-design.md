# M2 — ล่าหมาป่าผี: ต่อสู้ ได้ของ เก่งขึ้น (เอกสารออกแบบ)

สถานะ: **ร่าง รอเจ้าของอนุมัติ** · วันที่ 2026-11-06 · ต่อจาก M1 (PR #2)
อ้างอิง: `docs/spec-numbers.md`, `docs/skills.md`, `docs/gems.md`, `docs/art-style.md` (อนุมัติแล้ว) และภาพร่างหน้าจอ https://claude.ai/artifact/HAqT4xe2Q9GN7gTNrXtryN

ข้อที่มีป้าย **[ผมเลือกเอง]** คือสิ่งที่ Claude ตัดสินใจเอง เจ้าของแก้ได้ ส่วนที่เหลือมาจากคำตอบของเจ้าของหรือ spec ที่อนุมัติแล้ว

## 1. ทำไม และแบบไหนถึงเรียกว่าสำเร็จ
- **ทำไม:** ให้วงจรหลักของเกม "ล่ามอน → ได้ของ → เก่งขึ้น" หมุนได้จริงเป็นครั้งแรก
- **เจ้าของต้องการ:** หลบได้ ("ต้องมีท่าหลบ") และเล่นบนมือถือด้วยจอยใส ๆ แบบ ROV ที่ย้ายตามนิ้ว
- **สำเร็จ** เมื่อเจ้าของเปิดเกมแล้ว
  - ยิงฝูงหมาป่าตายได้ และกลิ้งหลบตอนหมาป่าโดดพุ่งได้ทันจังหวะ
  - เก็บของ เลเวลอัป ปลดสกิลใหม่
  - เปิดกระเป๋า เปลี่ยนธนู แล้วเห็นธนูในมือเปลี่ยน
- **ล้มเหลว (แม้จะทำงานได้ทางเทคนิค)** ถ้า
  - หมาป่าวิ่งเร็วกว่าเราจนหลบไม่ทัน หรือตายโดยไม่รู้ตัว
  - ปุ่มมือถือกดยาก หรือบังฉาก
  - ของที่ตกต้องเดินไปทับทีละชิ้นจนน่าเบื่อ

## 4. สิ่งที่เจ้าของตัดสินแล้ว
- ท่าหลบ: **กลิ้งได้ 8 ทิศและอมตะช่วงสั้น ๆ มีตั้งแต่ Lv1 และเก่งขึ้นตอน Lv5**
- ของดรอป: **ดูดเข้าตัวเมื่อเดินเข้าใกล้**
- เล็งเป้า: **ล็อกตัวที่ใกล้ที่สุดอัตโนมัติ** ถ้าไม่มีมอนในระยะให้ยิงไปทางที่หันอยู่
- สกิลใน M2: **ศรทะลวง + ศรกระจาย**
- ชุดเกราะใหม่ที่เห็นบนตัว: **ยังไม่ทำ**
- หน้าจอ: จอยใสแบบ ROV ที่ย้ายตามนิ้วในครึ่งซ้ายของจอ ปุ่มยิงใหญ่อยู่ขวาล่าง สกิล 4 ช่องเรียงเป็นวงโค้ง ปุ่มกลิ้งอยู่ทางซ้ายของสกิล และ**ยา 2 ปุ่มอยู่ข้างปุ่มกลิ้ง** (ย้ายมาจากข้างจอยตามที่เจ้าของสั่ง)
- ไอคอนสกิล: ศรกระจายใช้แบบ B กลิ้งหลบใช้แบบ B ที่เหลือใช้แบบ A (ไฟล์อยู่ใน `assets/skills/`)

## 5. ตัวเลขใหม่ (ต้องอนุมัติก่อนเขียนโค้ด แล้วจะคัดลงใน spec-numbers.md และ skills.md)
### 5.1 กลิ้งหลบ (แทนแถว "กลิ้งหลบ" เดิมในตารางสกิล)
| | Lv1–4 | ตั้งแต่ Lv5 |
|---|---|---|
| ระยะ | 64 px | 96 px |
| เวลากลิ้ง | 0.25 วิ | 0.3 วิ |
| อมตะ | 0.2 วิ แรก | 0.3 วิ (ตลอดการกลิ้ง) |
| คูลดาวน์ | 1.5 วิ | 1.5 วิ **[ผมเลือกเอง]** |
- **[ผมเลือกเอง]** เดิมใน spec Lv5 มีคูลดาวน์ 3 วิ ซึ่งนานกว่าของ Lv1 จะกลายเป็น "เก่งขึ้นแต่ใช้ได้ห่างขึ้น" ผมจึงเสนอให้คงไว้ที่ 1.5 วิ
- กลิ้งไปทางที่จอยชี้อยู่ ถ้าไม่ได้แตะจอยให้กลิ้งไปทางที่หันอยู่ กลิ้งระหว่างยิงได้โดยจะยกเลิกท่ายิง ไม่ใช้ MP

### 5.2 หมาป่าผี (ค่าพลังตาม spec ข้อ 4 ข้างล่างนี้คือพฤติกรรมที่เพิ่ม)
| ค่า | ตัวเลข [ผมเลือกเอง] |
|---|---|
| เห็นเราในระยะ | 160 px (ตัวหนึ่งในฝูงเห็น ทั้งฝูงไล่ตาม) |
| เลิกไล่ | ห่างจุดเกิดเกิน 320 px แล้ววิ่งกลับ ระหว่างกลับฟื้น HP เต็ม |
| เดินตอนว่าง | 50 px/วิ วนรอบจุดเกิด |
| วิ่งไล่ | 140 px/วิ (ตาม spec) |
| กัด | ระยะ 22 px · ง้าง 0.35 วิ · ดาเมจ ATK×1.0 · พักระหว่างกัด 1.2 วิ |
| โดดพุ่ง | ทำเมื่อเราอยู่ห่าง 60–130 px · **วงแดงเตือน 0.5 วิ** แล้วพุ่งเป็นเส้นตรง 140 px ใน 0.3 วิ · ดาเมจ ATK×1.5 · พักโดด 5 วิ · โดดได้ทีละตัวในฝูง |
| โดนยิง | กะพริบขาว 0.1 วิ · ถูกผลักถอย 6 px · ยิงขัดตอนง้างกัดไม่ได้ |
| ตาย | ล้มลงแล้วจางหายไปใน 0.6 วิ · เกิดใหม่หลัง 20 วิ (ตาม spec) |
- ดาเมจที่หมาป่าทำกับเรา ใช้สูตรเดียวกับ spec ข้อ 2 (DEF ของเราช่วยลดได้)

### 5.4 สกิลและ MP ใน M2b (ตัวเลขตาม skills.md / gems.md)
- ศรทะลวง 180% ทะลุทุกตัวในแนว ระยะ 220 px · CD 4 วิ · MP 8
- ศรกระจาย 5 ดอก พัด 45° ดอกละ 70% · CD 6 วิ · MP 12 · ปลดที่ Lv3
- สกิลล็อกเป้าแบบเดียวกับการยิงปกติ · ใช้ท่ายิงเดิม (ไม่ต้องทำท่าร่ายเวท)
- MP = 50+5(L−1) ฟื้น 6/วิ · ดาเมจ +5% และคูลดาวน์ −1% ต่อเลเวลสกิล

### 5.5 ฝูงในฉากทดสอบ **[ผมเลือกเอง]**
- 3 ฝูง ฝูงละ 3–4 ตัว เลเวลฝูงละ 1, 3 และ 5 วางห่างกันพอให้สู้ทีละฝูง
- ฉากทดสอบขยายเป็นประมาณ 60×40 ช่อง (1920×1280 px) กล้องตามตัวเรา

### 5.6 ของดรอปและกระเป๋า (M2b–M2c) **[ผมเลือกเอง]**
- โอกาสดรอปและระดับความหายากตาม spec ข้อ 5 · เจมที่ดรอปสุ่มชนิดเท่า ๆ กันจากรายการใน gems.md
- อุปกรณ์ที่หมาป่าผีดรอป: ธนูไม้ไผ่ · ธนูเขาควาย (Lv5) · ชุดพรานฝึกหัด · ชุดหนังหมาป่า (Lv4) · แหวน · สร้อย
- ค่าออฟชั่นสุ่มตาม spec เป็นช่วงของอุปกรณ์ Lv10 ส่วนอุปกรณ์ที่เลเวลต่ำกว่าให้คูณด้วย (เลเวลอุปกรณ์ ÷ 10) แต่ไม่ต่ำกว่า 30% ของช่วง
- แหวนและสร้อยไม่มีค่าหลัก มีเฉพาะออฟชั่นสุ่ม (ตาม spec ข้อ 6)
- กระเป๋า 24 ช่อง ยา แร่ และเจมชนิดเดียวกันซ้อนกันได้ช่องละ 99 · ถ้ากระเป๋าเต็ม ของจะไม่ถูกดูดและค้างอยู่บนพื้น พร้อมข้อความ "กระเป๋าเต็ม"
- เสีย EXP ตอนตายจะไม่ทำให้ EXP ติดลบหรือตกเลเวล · เลเวล 10 คือเพดานของเฟส 1 EXP จะหยุดที่นั่น
- บันทึกเกมอัตโนมัติเมื่อเลเวลอัป เก็บของ สวมใส่ และทุก 30 วินาที (ไฟล์ `user://save.json`)

## 6. หน้าจอและการควบคุม
- ใช้ภาพร่างหน้า "หน้าต่อสู้" "จอยใส 3 จังหวะ" และ "กระเป๋า" ตามลิงก์ด้านบน (ยาย้ายมาข้างปุ่มกลิ้งแล้ว)
- **จอยใส:** โซนแตะคือครึ่งซ้ายของจอ ถัดลงมาจากแถบสถานะด้านบน
  - ไม่แตะ: จางประมาณ 20% อยู่มุมซ้ายล่าง
  - แตะ: ย้ายมาใต้นิ้ว
  - ลาก: ปุ่มกลางตามนิ้ว ขอบวงสว่างฝั่งที่เดิน ลากเกินขอบวงจะเลื่อนตามนิ้ว
  - ปล่อยนิ้ว: กลับไปจาง
  - เดินได้ 8 ทิศ ความเร็วคงที่ 110 px/วิ ไม่มีเดินช้าตามระยะที่ลาก **[ผมเลือกเอง]**
- **ปุ่มขวา:** ยิง (กดค้างแล้วยิงต่อเนื่องตามคูลดาวน์) · สกิล 1–2 · ช่องที่ยังล็อกแสดงป้ายเลเวลที่ปลด · กลิ้ง · ยา HP/MP พร้อมตัวเลขจำนวน · ปุ่มที่ติดคูลดาวน์มีเงามืดและตัวเลขวินาที
- **แถบบน:** รูปฮีโร่ เลเวล หลอด HP/MP · ทอง · ปุ่มกระเป๋า · แผนที่ย่อ (ใน M2 เป็นกรอบว่างไว้ก่อน)
- **แถบ EXP** อยู่ขอบล่าง · ตัวเลขดาเมจลอยขึ้น โดยคริเป็นสีทองและมีเครื่องหมาย "!"
- **คีย์บอร์ด (PC):** WASD/ลูกศรเดิน · J/Space ยิง · K/Shift กลิ้ง · 1/2 สกิล · Q/E ยา · I/B กระเป๋า
- ปุ่มมือถือแสดงเมื่อเครื่องมีจอสัมผัส ถ้าไม่มีจะซ่อน **[ผมเลือกเอง]**
- ฟอนต์ไทย: ใช้ฟอนต์ที่รองรับภาษาไทยและใช้ได้ฟรีเชิงพาณิชย์ (เช่น Kanit, OFL) ฝังไว้ในโปรเจกต์

## 9. ข้อจำกัด
- Godot 4.5.1 ใช้ gl_compatibility · tile 32 · ฮีโร่อยู่ในช่อง 64×64 จุดเท้า (32,54) · ใช้ Y-sort
- ตัวเลขเกมทุกตัวต้องอยู่ในไฟล์ข้อมูลไฟล์เดียว เทสต์ใช้ไฟล์เดียวกัน และต้องตรงกับ spec
- ทุกช่วงต้องผ่านเทสต์ headless + ถ่ายภาพหน้าจอจริงด้วย xvfb ก่อนเปิด PR และห้ามอ้างว่าผ่านถ้าไม่ได้รันจริง
- งานเข้า main ผ่าน branch + PR ไม่ใช้บริการเสียเงินโดยไม่ได้รับอนุมัติ

## 10. สิ่งที่ปล่อยให้คนสร้างตัดสินเอง
- โครงสร้างโค้ดภายใน เช่น แยกเป็น component ของ HP, hitbox หรือ AI ของหมาป่า ตราบใดที่ตัวเลขมาจากไฟล์ข้อมูลไฟล์เดียว
- วิธีวาดหลอด HP และปุ่ม ใช้ Control ของ Godot ได้ โดยหน้าตาต้องตรงกับภาพร่าง
- เสียงยังไม่อยู่ในขอบเขต M2
