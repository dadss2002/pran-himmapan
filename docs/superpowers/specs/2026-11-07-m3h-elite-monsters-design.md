# M3h มอน Elite

สถานะ: **เจ้าของเลือกตัวเลขเองในคำถามแล้ว 2026-11-07**
คำขอเจ้าของ: "มอนเพิ่มระดับ elite ให้ตายยากขึ้นและ exp สูงขึ้น และอยากให้มีการบ่งบอกระดับให้ชัดเจน"
งบ PixelLab: 0 gen

## 1. ตัวเลข (data/balance.json → "elite") ใช้ต่อจากค่า horde ของ M3g
| ค่า | Elite เทียบกับมอนธรรมดาเลเวลเดียวกัน |
|---|---|
| โอกาสเกิด | **10%** ทุกครั้งที่มอนเกิดหรือเกิดใหม่ ทุกชนิด ทุกห้อง |
| HP | **× 4** |
| ATK | **× 1.5** |
| DEF | เท่าเดิม |
| EXP | **× 5** |
| ทอง | **× 3** |
| โอกาสดรอปของ (แร่ เจม อุปกรณ์) | **× 3** (ไม่เกิน 100%) |
| เกรดอุปกรณ์ที่ดรอป | **สูงขึ้น 1 ขั้น** จากที่สุ่มได้ (ธรรมดา→ดี … มหากาพย์→ตำนาน, ตำนานคงเดิม) |
| ถูกยิงแล้วกระเด็น | **ไม่กระเด็น** |

นิสัยไม่เปลี่ยน: Elite ของมอนที่ไม่ตีก่อน ก็ยังไม่ตีก่อน

## 2. หน้าตา (เจ้าของเลือก: ป้าย ★ + หลอดเลือดบนหัว)
- เหนือหัวมีดาวสีทองตามด้วยหลอด HP สั้น ๆ มีเฉพาะ Elite มอนธรรมดาไม่มี
- หลอดเลือดลดตามดาเมจ และหายไปตอนมอนตาย

## 3. ต้องตรวจ
- เทสต์ค่าคูณทุกค่า โอกาสเกิดประมาณ 10% ไม่กระเด็น เกรดดรอปสูงขึ้น 1 ขั้น และป้ายมีเฉพาะ Elite
- ภาพหน้าจอ Elite ในเกม
