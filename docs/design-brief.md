# PRAN: Hunter of Himmapan — Design Brief (ร่างจากการถาม 6 รอบ, 2026-11-06)

สถานะ: **เจ้าของยืนยันแล้ว 2026-11-06** ("ต่อ")

## ภาพรวม
- เกม 2.5D top-down (มุมมอง 3/4 แบบภาพป่าตัวอย่าง) แอ็กชัน RPG เล่นคนเดียว เซฟในเครื่อง
- โปรเจกต์แยกจาก SIAM FABLES (ซึ่งล็อกเป็น 3D chibi)
- เอนจิน: **Godot 4.5** พัฒนาผ่าน Claude Code (ยืนยันแล้ว: Godot 4.5.1 รัน headless + ถ่ายภาพหน้าจอผ่าน xvfb ได้ในเครื่องทำงานของ Claude)
- ธีม: ฉากป่าแฟนตาซีสวยแบบภาพตัวอย่าง + มอนและชื่อเป็นไทย (ป่าหิมพานต์)
- งานภาพทั้งหมด + แผนที่: **PixelLab** (โควตา 5,000 gen/รอบ, รีเซ็ต 2026-12-06)

## เผยแพร่
1. เว็บผ่าน **GitHub Pages** ก่อน (export แบบไม่ใช้ thread เพื่อไม่ต้องใช้ header COOP/COEP)
2. **Cloudflare Pages** ทีหลัง: ไฟล์ wasm ของ Godot ~35MB เกินลิมิต 25MiB/ไฟล์ → ต้องทำ build Godot แบบตัดโมดูลให้เล็กลงก่อน
- APK: สร้างในเครื่อง Claude ไม่ได้ (ดาวน์โหลด Android SDK ไม่ได้) — ถ้าต้องการ เจ้าของ build บนคอมเอง

## ขนาดพิกเซล
| องค์ประกอบ | ขนาด |
|---|---|
| Tile พื้นฐาน (grid หลัก) | 32×32 |
| Hero sprite | 48×48 (collision แยก ~20×16 ที่เท้า) |
| NPC | 32×32 หรือ 40×40 |
| ต้นไม้เล็ก / ใหญ่ | 64×64 / 96×128 |
| หิน ของตกแต่ง | 32–64 |
| สิ่งก่อสร้าง | 96–160 |
- ใช้ Y-Sorting ให้เดินหน้า/หลังต้นไม้ได้; วัตถุใหญ่ไม่ถูกจำกัดตาม tile

## ตัวละครแรก: นักธนู / นายพราน
- 8 ทิศ, แอนิเมชันหลัก ~6 ท่า (ยืน เดิน ยิง ร่ายสกิล โดนตี ตาย)
- ต่อสู้เรียลไทม์: จอยเดิน + ปุ่มโจมตี + ปุ่มสกิล 3–4 ปุ่ม (มือถือเป็นหลัก)
- ค่าสถานะ: **เพิ่มอัตโนมัติ** ตอนเลเวลอัป
- สกิล: **ปลดตามเลเวล + รูนที่ดรอปจากมอนเปลี่ยนรูปแบบสกิล** และ **เลือกสายอาชีพที่เลเวล 10**
  - พรานไพร: เรียกสัตว์ วางกับดัก ยิงพิษ
  - ศรเวท: ธนูธาตุ ไฟ / น้ำแข็ง / สายฟ้า
  - รูนใช้ได้กับทุกสกิล

## ของสวมใส่และไอเทม
- เห็นบนตัวละคร: **ชุดเต็มตัว 5 ชุด + ธนู 3 แบบ** (ชุดเปลี่ยนทั้งตัว ใช้ PixelLab transfer_outfit ~120 gen/ชุด)
- ออฟชั่นสุ่มบนไอเทม + ระดับความหายากตามสี
- ตีบวก +1 ถึง +10: เกิน +5 ตีไม่ติด **ลด 1 ขั้น** (≤ +5 เสียแค่วัตถุดิบ)
- ชุดแฟชั่น (cosmetic ไม่มีค่าสถานะ): ได้จาก **ดรอปบอส/คราฟต์ และซื้อด้วยเงินในเกม** (ไม่มีเงินจริง)

## เนื้อหาเฟสแรก
- **แผนที่เดียว**: ป่าแบบภาพตัวอย่าง (tileset + วางพร็อพด้วย PixelLab)
- มอน: **ผีกองกอย**, **หมาป่าผี** (มาเป็นฝูง), บอส **เสือสมิง** (ดรอปชุดแฟชั่น/รูนหายาก)
- ตาย: กลับจุดเกิด เสีย EXP 5% ของเลเวล ไม่ตกเลเวล ของไม่หาย

## งบ PixelLab โดยประมาณ (จาก 5,000 gen)
- ฮีโร่ 8 ทิศ + 6 ท่า ~50 · ชุดเต็มตัว 5 ชุด ~600 · ธนู 3 แบบ ~60–150 · มอน 2 + บอส ~80–120 · tileset + พร็อพ ~50–150 · ไอคอนไอเทม/รูน ~10 ต่อชิ้น
- รวมเฟสแรกราว 1,000–1,400 gen

## ยังต้องออกแบบตัวเลขก่อนเขียนโค้ด
- สูตรดาเมจ, เส้น EXP, ตารางดรอป, อัตราตีบวก, รายชื่อสกิล/รูนพร้อมตัวเลข → จะเขียนเป็น spec ให้เจ้าของดูก่อน
