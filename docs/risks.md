# ความเสี่ยงรวม — PRAN: Hunter of Himmapan

เริ่ม 2026-11-09 · เจ้าของ: "แจ้งผมตลอดว่าอะไรที่เสี่ยงจะเกิดบัค หรืออื่นๆ … ถ้ามันบอกเมื่อไหร่ว่าให้อันนั้นอันนี้ตัดสินจาก server นี่ต้องดูเป็นพิเศษ"
กติกา: ทุกงานอัปเดตไฟล์นี้ · ทุกรายงานมีหัวข้อ **[ความเสี่ยง]** · ผู้ตรวจอิสระตรวจเรื่องโกง/ช่องโหว่ทุกงาน
เจ้าของเลือกแล้ว (2026-11-09): อนาคตจะมี **แลก/ขายของระหว่างผู้เล่น หรือเล่นด้วยกัน** และ **ร้านเติมเงิน / ขายของจริง** · ตอนนี้ (เล่นคนเดียว) กันแก้เซฟ "แบบพอดี: ตรวจทุกค่าในเซฟให้อยู่ในช่วงที่เป็นไปได้ + ลายเซ็นกันแก้มือ"

ระดับ: 🔴 ต้องออกแบบก่อนทำฟีเจอร์ · 🟠 ควรแก้เร็ว · 🟢 รู้ไว้/รับได้

## 1. โกง / ช่องโหว่
| # | ระดับ | เรื่อง | สถานะ / ทางแก้ |
|---|---|---|---|
| S1 | 🔴 | **ตอนนี้ทุกอย่างตัดสินในเครื่องผู้เล่น** (ดาเมจ ดรอป ทอง EXP เลเวล ตีบวก) และเซฟอยู่ในเบราว์เซอร์ — ใช้กับแลกของ/เล่นด้วยกัน/ร้านเติมเงินไม่ได้เลย | ก่อนเริ่มฟีเจอร์ออนไลน์ต้องมี **เซิร์ฟเวอร์ตัดสิน**: ดรอป/ทอง/ไอเทม/ตีบวก/ซื้อขาย คำนวณและเก็บบนเซิร์ฟเวอร์ เครื่องผู้เล่นแค่แสดงผล · เขียน spec สถาปัตยกรรมออนไลน์แยก (ยังไม่เริ่ม) |
| S2 | 🔴 | ร้านเติมเงิน: ใบเสร็จ/การจ่ายเงินต้องตรวจที่เซิร์ฟเวอร์ (ห้ามเชื่อเครื่องผู้เล่น), คืนเงิน/ยกเลิก, กฎหมายผู้บริโภค/ภาษี, ร้านแอป (Apple/Google) บังคับใช้ระบบจ่ายเงินของเขาสำหรับของในแอป | ต้องใช้ผู้ให้บริการจ่ายเงิน + เซิร์ฟเวอร์ — มีค่าใช้จ่าย ต้องอนุมัติก่อน |

| S5 | 🟠 | เล่นคนเดียวตอนนี้: แก้เซฟในเบราว์เซอร์ได้ (ทอง เลเวล ของ) — มีตัวกรองบางส่วน (เลเวลไอเทม ≤ 10, ทิ้งข้อมูลเสีย) | งานถัดไป: ตรวจทุกค่าให้อยู่ในช่วงที่เป็นไปได้ + ลายเซ็น (HMAC) — **ลายเซ็นกันได้แค่คนทั่วไป** เพราะกุญแจอยู่ในตัวเกม คนเก่งยังแกะได้ (ไม่มีเซิร์ฟเวอร์กันได้ 100%) · เซฟเล่นคนเดียวห้ามนำไปใช้ตอนเปิดออนไลน์ (เริ่มตัวละครออนไลน์ใหม่ หรือย้ายผ่านการตรวจ) |

| S7 | 🟢 | สคริปต์ช่วยเล่น/บอทฟาร์ม (เล่นคนเดียวไม่กระทบใคร) | สำคัญเมื่อมีแลกของ — จำกัดอัตราและตรวจบนเซิร์ฟเวอร์ |
